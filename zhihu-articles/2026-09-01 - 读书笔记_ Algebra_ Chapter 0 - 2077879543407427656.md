## Preliminaries: Set theory and categories

### Function between sets

Second view of bijections: if $f:A\to B$ is a bijection, then can define a function $g:B\to A$ . $g$ indicates that $g\circ f=\text{id}_A$ . Left inverse $iff$ injective, right inverse $iff$ surjective.

**monomorphism: **monomorphism $iff$ injective: $\forall Z;\alpha',\alpha'':Z\to A$ , $f\circ \alpha'=f \circ \alpha''\Rightarrow \alpha'=\alpha''$ . Surjective is epimorphism.

**canonical decomposition: **Let $f:A\to B$ be a function. Define an equivalence relation on $A$ by $a\sim a'\iff f(a)=f(a')$. The canonical decomposition of $f$ is

$ A\twoheadrightarrow A/{\sim}\xrightarrow{\cong}\operatorname{im}f\hookrightarrow B, $

or equivalently,

$ f=\iota\circ\bar f\circ\pi. $

Here the map is decomposed into a **surjection**, then a **bijection**, then an **injection**.

The canonical projection $\pi:A\to A/{\sim}$ is defined by $\pi(a)=[a]$. It is surjective because every equivalence class is represented by some $a\in A$.

The induced map $\bar f:A/{\sim}\to\operatorname{im}f$ is defined by $\bar f([a])=f(a)$. This is well-defined because $[a]=[a']$ implies $a\sim a'$, hence $f(a)=f(a')$. It is bijective: equal outputs imply equal equivalence classes, and every element of $\operatorname{im}f$ is reached.

The inclusion map $\iota:\operatorname{im}f\hookrightarrow B$ is defined by $\iota(b)=b$. It simply regards an element of $\operatorname{im}f$ as an element of $B$, and is therefore injective.

Thus for every $a\in A$,

$ a\xmapsto{\pi}[a]\xmapsto{\bar f}f(a)\xmapsto{\iota}f(a), $

so $(\iota\circ\bar f\circ\pi)(a)=f(a)$, hence $f=\iota\circ\bar f\circ\pi$.

### Categories

A category C consists of a class $Obj(C)$ and $Hom_C(A,B)$ of morphisms, which have porperties of identity and composition.

### Morphisms

A morphism $f \in \operatorname{Hom}_{\mathcal{C}}(A,B)$ is an **isomorphism** if it has a (two-sided) inverse under composition: that is, if $\exists g \in \operatorname{Hom}_{\mathcal{C}}(B,A)$ such that

$ gf = 1_A,\qquad fg = 1_B. $

A category called groupoids if every morphism is inversible. The endomorphism is $f: A\to A$ , and automorphism is inversible endomorphism. $Aut_C(A)$ is a group. Monomorphism is injective while epimorphism is surjective. Monomorphism and epimorphism $\to$ isomorphism not hold for all categories.

### Universal properties

$I$ is initial: $\forall A\in Obj(C)$ , $Hom_C(I,A)$ is a singleton, having single element. $F$ is final respectively. Universal property defines an object by its relations to all other objects. For example, pair $(\pi, A/\text{~})$ is an initial object of this category, product owns terminal type universal property and coproduct(like disjoint) is an initial.

### The category Grp

$\varphi:G\to H$ define a group homomorphism if $\varphi(a*b)=\varphi(a)*\varphi(b)$ where $\forall a,b\in G$ . For instance, $\det: GL\to R^{\times}$ is a group homomorphism as $\det(AB)=\det A\det B$ . $G\times H$ is a product in Grp.

### Group homomorphisms

Let $g\in G$ be an element of finite order, $|\varphi(g)|$ divides $|g|$ ( $|\varphi(g)|||g|$ ). For instance, $\mathbb{Z}/n\mathbb{Z}\to \mathbb{Z}$ is a trivial homomorphisms as there exits no finite order in $\mathbb{Z}$ except 0, so $\varphi(g)=0,\forall g$ . An isomorphism is that $|\varphi(g)|=|g|$ and $G$ is commutative iff $H$ is commutative. Example $C_6\to S_3$ is not isomorphism can be judged by $S_3$ is not commutative and the order of element in two group are not same. $\text{Hom}_{Ab}(G,H)$ itself is an abelian group.

For $A=\{1,...,n\}$ , $\mathbb{Z}^{\oplus n}$ is a free abelian group on $A$ . We have $F^{ab}(A)\cong\mathbb{Z}^{\oplus A}$ .

### Subgroups

$H$ is a subgroup of $G$ iff $\forall a,b\in H$ , $ab^{-1}\in H$ . Such property make sure identity, inverse and closure.

$\langle A\rangle = \bigcap_{\substack{H\le G\\H\supseteq A}} H$ is the smallest subgroup of $G$ containing $A$ . For instance, $A=\{6\}$ so the $\langle A\rangle=6\mathbb{Z}$ .
